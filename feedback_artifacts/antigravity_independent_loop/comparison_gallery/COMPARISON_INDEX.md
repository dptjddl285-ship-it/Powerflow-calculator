# ⚡ Antigravity 전용 독립 비교 갤러리 (Original vs New Detection)

이 디렉터리는 기존 폴더를 건드리지 않고, **원본 이미지(Original Raw)**와 **새로 검출한 결과(New Detection Boxed)**를 좌우 1:1로 결합하여 한눈에 쉽게 대조·검수할 수 있도록 만든 **독립 전용 갤러리**입니다.

## 📂 폴더 구조
```
feedback_artifacts/antigravity_independent_loop/comparison_gallery/
  ├── index.html         <-- 브라우저에서 바로 열 수 있는 전체 대조 뷰어 (클릭 시 확대)
  ├── original/          <-- 복사해온 원본 이미지 20장
  ├── boxed/             <-- 새로 박스를 친 검출 이미지 20장
  └── side_by_side/      <-- [왼쪽: 원본 | 오른쪽: 새 검출] 라벨 결합 이미지 20장
```
